☁️ نسخ احتياطي تلقائي على Google Drive

بعد كل تعديل (بعد ٤٥ ثانية من آخر حركة) بيترفع ملف kayan-latest.json على Drive بتاعك جوا فولدر «KAYAN Backups»، وبيتعمل نسخة يومية بتاريخ اليوم (بيتحتفظ بآخر ١٤ يوم). المنصة بتشوف بس الملفات اللي هي عملتها، مش باقي Drive.

⚠️ الصفحة مفتوحة كملف على الجهاز (file://) — جوجل مش بيسمح بتسجيل الدخول من الوضع ده. لازم المنصة تتفتح من موقع https (زي GitHub Pages) أو localhost.
إزاي أجيب الـ Client ID؟ (مرة واحدة)
  1. افتح console.cloud.google.com وأنشئ مشروع جديد.
  2. APIs & Services ← Library: ابحث عن Google Drive API واضغط Enable.
  3. OAuth consent screen: اختار External، واكتب اسم التطبيق، وضيف إيميلك في Test users.
  4. Credentials ← Create credentials ← OAuth client ID ← النوع Web application.
  5. في Authorized JavaScript origins اكتب عنوان موقعك بالظبط (مثلًا https://اسمك.github.io) — من غير مسار بعده.
  6. انسخ الـ Client ID (بينتهي بـ apps.googleusercontent.com) والصقه تحت واضغط «ربط».

جوجل بتدّي تصريح لمدة ساعة؛ لو خلص، المنصة بتجدده بمجرد ما تضغط أي حاجة في الصفحة (ممكن تظهر نافذة صغيرة بتتقفل لوحدها).

☁️ المزامنة السحابية (Supabase)

البيانات بتتخزّن أساسًا على الجهاز (IndexedDB) وبتشتغل من غير نت. أول ما يبقى فيه نت بتتنسخ للسحابة تلقائيًا، وتفتحها من أي جهاز بنفس الإيميل.

إعداد Supabase (مرة واحدة)

1) أنشئ مشروع مجاني على supabase.com. 2) من Authentication ← Providers ← Email ألغِ «Confirm email». 3) من SQL Editor شغّل الكود ده. 4) انسخ Project URL ومفتاح anon من Settings ← API.

create table kayan_sync(
  id text primary key default 'main',
  data jsonb not null,
  updated_at bigint not null);
alter table kayan_sync enable row level security;
create policy "allowed users" on kayan_sync for all to authenticated
  using ((auth.jwt()->>'email') in ('email1@gmail.com','email2@gmail.com'))
  with check ((auth.jwt()->>'email') in ('email1@gmail.com','email2@gmail.com'));

رأس المال

سجّل رأس المال اللي بتشتغل بيه، وزوّده في أي وقت (إضافة) أو اسحب منه. النظام بيحسب عليه المشتريات والمبيعات والمصروفات ويطلّع السيولة المتاحة، وبيظهر ملخصه في أعلى الصفحة. الأرباح والخسائر بتتضاف أو بتتخصم من رأس المال تلقائي، والسحب الشخصي بيخصم منه بس من غير ما يأثر على الأرباح أو الحسابات.

كشف السيولة على رأس المال

أين رأس المال دلوقتي؟

الربح المحقّق = ربح الشحنات اللي اتباعت بعد مصروفاتها (مصروفات البيع خصمت من البيع، ومصروفات الشراء دخلت في تكلفة المخزون). إجمالي المشروع = رأس المال السائل (الكاش + لنا عند العملاء − علينا للمصانع) + بضاعة المخزن بتكلفة الشراء؛ فشراء بضاعة وتخزينها بيحوّل جزء من السيولة لمخزون من غير ما ينقص قيمة المشروع.
